# Page structure

The wiki page's shape: these sections, this order, nothing else. The whole
page — title, headings, bodies, footer — is written in your owner's
language; the English names below are the reference shape you translate,
never required text. `{OWNER}` is your owner's name.

```markdown
# About {OWNER}

## Identity

## Key contacts

## Communication style

## Work patterns

## Working preferences

## Personal context

## Writing samples

## Connected tools

## Sources

---
This wiki is a snapshot built from limited data; it updates as we work together.
```

The last line is the snapshot footer: one line, in your owner's language,
after a `---` rule. Every page ends with exactly one.

What goes inside each section is SKILL.md's *What the page covers* table;
how each line is written is its *Page format* section.
